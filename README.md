# SmartExpense – Personal Finance Analytics Dashboard

SmartExpense is a responsive finance dashboard that helps users track income, expenses, savings, and spending trends through interactive charts and analytics.

## Features

- Add, edit, and delete expenses
- Track income and savings
- Category-wise expense analysis
- Interactive charts using Chart.js
- Monthly spending insights
- Search and filter transactions
- Local Storage for data persistence
- Responsive design for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- Local Storage
- GitHub Pages

## How It Works

1. Users add income and expenses.
2. Data is stored using Local Storage.
3. Dashboard calculates financial metrics.
4. Charts update automatically to visualize spending patterns.
5. Insights help users understand their financial habits.
